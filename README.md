# 📦 Stock In & Out

A Streamlit app for tracking stock inventory with photo capture and editing.

## Features

- Add, search, and manage stock items
- Stock in / out buttons and quantity editing
- Take a photo (webcam) or upload one per item
- Edit photos: rotate, flip, crop, brightness, contrast, saturation, sharpness, blur, and colour modes
- Download edited photos

## Run locally

```bash
pip install -r requirements.txt
streamlit run main.py
```

## Data

Data is stored in `stock_data.json` and photos in `stock_images/`.
